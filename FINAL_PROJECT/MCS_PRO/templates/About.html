About WI-WN

WI-WN (Wireless Intelligence – Wireless Network) is a Wireless Network Security Application designed for monitoring, detecting threats, and managing network security tools.

Features include packet sniffing, attack detection, password management, network diagnostics (Ping / Traceroute), SSID detection, and more.

Built as a graduation / portfolio project in Communications Technology.
